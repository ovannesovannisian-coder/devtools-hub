# DevTools Hub

A free, private, client-side collection of everyday developer tools. **No uploads, no tracking, no accounts** — everything runs locally in your browser (and works offline after first load).

**Live:** https://ovannesovannisian-coder.github.io/devtools-hub/

## Tools

| Tool | Description |
|------|-------------|
| 🧩 JSON Formatter & Validator | Pretty-print, minify, validate with error location |
| 🔐 Base64 Encode / Decode | UTF-8 safe, error-tolerant |
| 🔗 URL Encode / Decode | Percent-encoding for URLs and query strings |
| #️⃣ Hash Generator | SHA-1 / SHA-256 / SHA-384 / SHA-512 via browser SubtleCrypto |
| 🧪 Regex Tester | Live JavaScript RegExp with flags and match highlighting |
| ⏱️ Timestamp Converter | Unix ↔ ISO ↔ local time (seconds & ms) |
| 🔄 CSV ⇄ JSON | Comma / semicolon / tab delimiters, quoted-field aware |
| 🎫 JWT Decoder | Decode header & payload client-side (no signature verification) |

## Why client-side

- Your data never leaves the device — ideal for JWTs, configs, and one-off text you'd rather not paste into a server-side tool.
- Free forever, no accounts, no rate limits.
- Fast: no network round-trips after load.

## Usage

Open the live page, pick a tool, paste your input, click the action. Output is copied with one click.

## Quick navigation

Press `Ctrl+K` (or `Cmd+K`) while on the page to jump to any tool.
